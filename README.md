# Autonomous Agricultural Grain Silo Aeration & Quality Optimization Hub
Spring Boot + MySQL project implementing silo master data, cooperative/vendor masters, telemetry, automatic fan triggering, invoices, vendor bills, payment status, dashboard and P&L.
## Run
1. Install Java 17+ and MySQL.
2. Edit `src/main/resources/application.properties` and replace `YOUR_MYSQL_PASSWORD`.
3. In VS Code terminal run `mvnw.cmd spring-boot:run`.
4. Open `http://localhost:8080`.
